# SchoolSync – CRM-Oriented Architecture

This branch implements a modular, scalable architecture for SchoolSync, treating it as a CRM-style school ecosystem.

- Backend: Node.js, Express, PostgreSQL, Prisma, JWT, Google OAuth
- Web: React, Vite, Tailwind CSS
- Mobile: React Native

See `backend/`, `web/`, and `mobile/` folders for service and UI structure.
